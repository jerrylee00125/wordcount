## 功能特色

- 輸入或貼上文字後即時計算，不需另外送出。
- 同時顯示含空白與不含空白的總字元數。
- 統計中文字、英文字母、英文單字、數字、標點符號、Emoji、行數與段落數。
- 以甜甜圈圖呈現文字組成，圖例數字會與統計卡同步更新。
- 正確處理常見 Unicode 內容，例如罕用中文字、全形數字、重音字母與組合式 Emoji。
- 支援清除文字及複製文字，並提供清楚的操作提示。
- 響應式版面可配合桌機、平板與手機螢幕自動調整。
- 支援目前的淺色主題與深墨綠色主題，並可從頁首按鈕快速切換。
- 第一次開啟時會跟隨裝置的淺色／深色設定，手動切換後會記住選擇。
- 所有計算皆在瀏覽器本機完成，輸入內容不會傳送到後端伺服器。

## 統計項目

| 項目 | 計算方式 |
| --- | --- |
| 總字元數（含空白） | 計算使用者實際看見的字元，包含空格、Tab 與換行 |
| 總字元數（不含空白） | 總字元數扣除所有空白字元 |
| 中文字數 | 計算 Unicode Han 漢字，包含常用字與延伸區罕用字 |
| 英文字母數 | 計算 Unicode 拉丁字母，除了 A–Z、a–z，也包含 é、ü、ñ 等重音字母 |
| 英文單字數 | 依英文單字邊界判斷，計算含拉丁字母的單字片段 |
| 數字數 | 計算 Unicode 十進位數字，包含半形與全形數字 |
| 標點符號數 | 計算中英文 Unicode 標點符號 |
| Emoji 數 | 以完整圖素群計算；家庭、膚色、國旗與鍵帽 Emoji 各算 1 個 |
| 空白字元數 | 包含一般空格、全形空格、Tab 與換行等空白字元 |
| 其他字元數 | 不屬於上述字元分類的內容 |
| 行數 | 包含空白行；文字結尾的換行也會產生最後一個空白行 |
| 段落數 | 以一個以上的空白行分隔段落，單純換行仍視為同一段 |

字元分類採互斥計算，因此下列項目的加總一定會等於「總字元數（含空白）」：

```text
空白 + 數字 + 中文 + 拉丁字母 + 標點 + Emoji + 其他
= 總字元數（含空白）
```

> 「英文字母數」實際採 Unicode 拉丁文字系統判定，因此也會納入其他歐洲語言常見的重音字母；「英文單字數」則是另一個獨立統計項目。

## Unicode 與 Emoji 計數

本工具優先使用 `Intl.Segmenter` 依「圖素群」（grapheme cluster）切分文字，而不是直接計算 UTF-16 編碼單位。因此，畫面上看起來是一個完整符號的內容會盡量只算一個字元，例如：

| 輸入內容 | 計數結果 |
| --- | ---: |
| `😆` | 1 個 Emoji |
| `👨‍👩‍👧‍👦` | 1 個 Emoji |
| `👍🏽` | 1 個 Emoji |
| `🇹🇼` | 1 個 Emoji |
| `1️⃣` | 1 個 Emoji |
| `嗨` | 1 個中文字 |
| `１２` | 2 個數字 |

若瀏覽器不支援 `Intl.Segmenter`，程式會自動改用 Unicode code point 方式進行基本計數。

## 使用方式

### 1.線上使用

直接開啟 [👉GitHub Pages 線上版👈](https://jerrylee00125.github.io/wordcount/)，在輸入框貼上或輸入文字即可查看結果。

### 2.在本機執行

1. 下載或複製此儲存庫。
2. 使用瀏覽器開啟 `index.html`。
3. 在文字框輸入內容，所有統計會即時更新。

這是一個單一 HTML 的靜態網站，不需安裝套件、不需建置，也不需啟動後端服務。

## 主題切換

- 點選頁首右上角的「深色模式」或「淺色模式」按鈕即可切換外觀。
- 第一次造訪且尚未選擇主題時，網站會跟隨裝置的系統設定。
- 手動切換後，網站會使用瀏覽器的 `localStorage` 保存主題偏好；下次開啟仍會套用相同主題。
- 主題功能只保存 `light` 或 `dark` 設定，不會儲存輸入框中的文字內容。
